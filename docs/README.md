## Suggested Reading Order

1. Read [Getting Started](./getting-started.md) for the quickest path to using the library.
2. Read [Architecture](./architecture.md) if you want to understand the service boundary and data flow.
3. Read [Configuration](./configuration.md) to learn how runtime settings are selected.
4. Read [Backends](./backends.md) to see which storage and model providers are available.
5. Read [Provider Adapters](./providers.md) to plug in OpenAI, Gemini, Ollama, or Anthropic.
6. Read [Examples](../examples/README.md) for runnable walkthroughs, including a provider-backed example.
